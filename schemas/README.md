# Agent Plugins schemas

These are the official Agent Plugins 1.0.0 schema documents retrieved on October 19, 2026:

- https://agent-plugins.org/schemas/1.0.0/plugin.schema.json
- https://agent-plugins.org/schemas/1.0.0/mcp.schema.json

Validation uses local copies and does not fetch remote schemas during installation. The normative specification also defines semantic and path-containment requirements tested by this repository.
